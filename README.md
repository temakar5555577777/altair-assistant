# Altair Assistant

Голосовой ассистент для Windows 10/11 (x64). Это собственная реализация того же класса продуктов, что Luxify Assistant. Все функции, которые у Luxify входят в подписку Plus, здесь открыты сразу. Плюс исправлены недочёты, на которые жалуются пользователи в отзывах.

Стек: **C# / .NET 9 / WPF**, установщик **Velopack**, офлайн-распознавание **Vosk**, звук **NAudio**.

## Установка

1. Откройте [Actions](../../actions), последнюю зелёную сборку, артефакт **Altair-Setup**.
2. Распакуйте архив и запустите `Altair.Assistant-win-Setup.exe`. Предупреждение SmartScreen появляется, потому что у установщика нет цифровой подписи: «Подробнее» → «Выполнить в любом случае».
3. При первом запуске скачается модель распознавания речи, около 50 МБ.
4. Скажите **«Альтаир, открой ютуб»**.

## Что исправлено по отзывам о Luxify

| Жалоба | Решение |
|---|---|
| Лимиты ИИ кончаются за 20 минут | Свой ключ без лимитов Altair, локальные модели, честный счётчик |
| Агент слабый и не видит экран | Скриншот, OCR и UI Automation в каждом шаге |
| ИИ доступен только по подписке | Чат и все функции открыты |
| Мало голосов, нельзя свои ответы или wav | Свои аудиофайлы и клонирование голоса |
| Нет случайных вариантов ответа | Пул ответов с весами |
| Нельзя запустить Python | Действие «Python-скрипт» |
| Курсор «телепортируется» | Плавное движение по кривой Безье |
| Команды долго настраивать | ИИ создаёт команду по описанию, запись макросов, 6 паков |
| Не понимает оборванные фразы | Нечёткое сопоставление и перепроверка второй моделью |

## Ограничения

- **Окна UAC** программно нажимать нельзя: это защищённый рабочий стол Windows. Вместо этого есть опция «Запуск от администратора без запроса»: одно подтверждение UAC при включении.
- **Озвучка системных уведомлений Windows** требует MSIX-упаковки (API `UserNotificationListener`). Сейчас озвучиваются уведомления самого Altair и чат Twitch.
- **Snapse** в этой версии распознаёт щелчки пальцами и хлопки через микрофон. Как устроен Snapse у Luxify, неизвестно.
- **Запись экрана** работает только при установленном ffmpeg: `winget install Gyan.FFmpeg`.
- Голоса персонажей из фильмов и игр (Джарвис, GLaDOS и др.) не включены: на них есть чужие права. Свой голос создаётся через Fish Audio по своему образцу.

## Структура

```
src/Altair.Core      — платформонезависимое ядро: модели, сопоставление фраз, выражения, сценарии,
                       триггеры, ИИ-провайдеры, агент, Telegram, умный дом, MCP, OBS, Twitch, второй ПК
src/Altair.Windows   — Windows: ввод (SendInput), окна, звук, Vosk, озвучка, экран/OCR/UIA, хуки, события
src/Altair.App       — WPF-приложение: страницы, оверлеи, трей, самопроверка (--selftest)
tests/               — модульные тесты ядра (xUnit)
extension/           — расширение браузера (Manifest V3)
```

Сборка: `dotnet publish src/Altair.App -c Release -r win-x64 --self-contained`. CI на GitHub Actions на каждый push запускает тесты, сборку, самопроверку на Windows и упаковку установщика.

## Данные

Всё хранится локально в `%AppData%\AltairAssistant`: настройки, команды, журналы, модели. Ключи API хранятся там же, открытым текстом в `settings.json`.
